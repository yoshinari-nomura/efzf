* efzf とは

efzf は，Emacs の強力な補完 UI (Vertico, Orderless など) をターミナル上で
fzf のように使うためのシェルスクリプトと Emacs Lisp パッケージです．

efzf はバックグラウンドで emacsclient を呼び出してターミナル上に
一時的な UI を展開し，標準入力や指定されたソースからの項目選択を支援します．

利用例:
: ps aux | efzf | awk '{print $2}' | xargs kill

efzf:
#+begin_example
Usage: efzf [-a action] [-p prompt] [-q query] [-s|-S] [-i|-I]
  -a ACTION  Emacs action (efzf-action-ACTION):
               pipe (default): select item from stdin
               file:           select file
               directory:      select directory
  -p PROMPT  prompt string
  -q QUERY   initial query
  -s / -S    sort / do not sort candidates (default: -S)
  -i / -I    case-insensitive / case-sensitive matching
             (default: follow Emacs settings)
#+end_example

* ファイル一覧

現在，このプロジェクトは，以下の 3つのファイルからなっています．

1) =efzf.el= : Emacs 側の基盤ロジックとアクション群
2) =efzf= : スタンドアロンで動作する Bash スクリプト
3) =efzf.zsh= : Zsh のキーバインドとして動作するウィジェット設定の例

* インストールとセットアップ
** 前提条件

efzf は emacsclient 経由で Emacs を呼び出すため，
Emacs をサーバーとして起動しておく必要があります．
=init.el= に以下を追加するか， =emacs --daemon= で Emacs を起動してください．

#+begin_src elisp
  (require 'server)
  (unless (server-running-p)
    (server-start))
#+end_src

efzf は Emacs の標準の補完 UI でも動作しますが，
Vertico などの補完 UI と組み合わせて使うことを想定しています．
以下は =init.el= の設定例です．

#+begin_src elisp
  (use-package vertico
    :ensure t
    :init (vertico-mode))

  (use-package orderless
    :ensure t
    :custom
    (completion-styles '(orderless basic))
    (completion-category-overrides
     '((file (styles basic partial-completion)))))

  (use-package marginalia
    :ensure t
    :init (marginalia-mode))

  ;; Keep minibuffer history (Vertico uses it for sorting)
  (use-package savehist
    :init (savehist-mode))
#+end_src

テーマが背景色を設定している場合，efzf の画面はその背景色で表示されます．
端末の背景色を使いたい場合は，以下のように設定してください．
この設定は， =emacsclient -t= で開く全ての端末フレームに適用されます．
テーマと端末の背景の明暗が異なる場合は，文字が読みにくくなることがあります．

#+begin_src elisp
  (defun my-use-terminal-background ()
    (unless (display-graphic-p)
      (set-face-background 'default "unspecified-bg" (selected-frame))))

  (add-hook 'server-after-make-frame-hook #'my-use-terminal-background)
#+end_src

** Emacs Lisp パッケージのインストール

efzf.el は [[https://melpa.org/][MELPA]] に登録されています．
パッケージングシステムを正しく設定している場合，
=M-x= =package-install= =efzf= でインストールできます．
詳しくは [[https://github.com/melpa/melpa#usage][MELPA usage]] を参照してください．

** CLI コマンドのインストール

~M-x efzf-install-scripts~ を実行すると，
=efzf= と =efzf.zsh= のコピー先を対話的に尋ねてコピーします．
既定のコピー先は，それぞれ =~/.local/bin/= と =~/.zsh/= です．

コピー後，以下の設定をしてください．

- =efzf= のコピー先に =PATH= を通す
- =.zshrc= で =efzf.zsh= を読み込む
  #+begin_src shell
    source ~/.zsh/efzf.zsh
  #+end_src

パッケージを更新した場合は， ~M-x efzf-install-scripts~ を再度実行してください．

* 利用方法

** 標準入力からのリストを絞り込み

=fzf= と同じように利用できます．
: ps aux | efzf | awk '{print $2}' | xargs kill

各行を NUL 文字で区切ると，NUL より前が選択肢として表示され，
NUL より後が選択時に出力されます．NUL を含まない行は，行全体が
表示され，そのまま出力されます．

: ps aux | awk 'NR>1 {print $11 "\0" $2}' | efzf | xargs kill

同じ選択肢が複数ある場合は，最初の行の値が出力されます．

** Emacs が持つ情報からの絞り込み

パイプの先ではなく，Emacs が持つ特定の action を指定して実行できます．
現在は，ファイルを選択する file と，ディレクトリを選択する
directory が実装されています．recentf や project などの情報から絞り込むなどの
用途が考えられるでしょう．

: vim $(efzf -a file)

また，zsh のウィジェットとしても利用できます．
=efzf.zsh= 中のサンプルを参照してください．

例えば，history-incremental-search-backward の実装です．
#+begin_src shell
  efzf-history-incremental-search-backward() {
    zle -I
    local selection=$(fc -nlr 1 | awk '!a[$0]++' | efzf) || return
    BUFFER="$selection"
    CURSOR=$#BUFFER
    zle reset-prompt
  }

  zle -N efzf-history-incremental-search-backward
  bindkey '^R' efzf-history-incremental-search-backward
#+end_src

* 開発者情報

efzf は， =emacsclient -t= を開き， =efzf-run-action= 関数経由で
=efzf-action-{action}= を呼出し，その結果を出力します．

例えば「最近 Emacs で開いたファイル一覧から選択する」機能を追加したい場合は，
以下の action を実装します．
この例では， =recentf-mode= が有効になっている必要があります．

#+begin_src elisp
  (defun efzf-action-recentf (options)
    (let ((prompt (or (plist-get options :prompt) "Select file: ")))
      (condition-case nil
          (expand-file-name
           (completing-read prompt recentf-list nil t))
        (quit nil))))
#+end_src

そして以下のように使えます．
: vim $(efzf -a recentf)

action 関数は，以下の環境で実行，また動作が期待されています．
+ =current-buffer= に pipe からの出力が入っています．
  使うかどうかは，action 次第です．
+ =default-directory= は，efzf のカレントディレクトリです．
+ =options= という 1つの plist を引数として取ります
  + efzf が action 固有の情報を入れているかもしれません．
+ 関数の値は，1つの文字列か nil です．
